# Maintainer outreach

ARE is looking for maintainers of Agent hosts, MCP clients, build tools, and
test frameworks who want a task-scoped residue checkpoint.

Useful integration feedback includes:

- where the host can begin and end an exact task observation;
- which workspace and task-temp roots it can declare safely;
- which process or port ownership signals are available without exposing
  command lines, environment values, or secrets;
- how the host presents evidence and requests cleanup authorization; and
- what stable identity it can recheck after authorized cleanup.

Please open a repository issue with a sanitized workflow. Do not include
credentials, raw command lines, environment values, proprietary paths, source
code, or full transcripts.
